# B 면접 설명 — FC 온라인

연습용 답변. 해당 이벤트에 직접 참여했다고 말하지 않는다. 본인의 보상·스쿼드 관심 경험과 공식 회차 분석은 별개다.

## 30초
FC KICK-OFF 이벤트에서 보상 수령과 경기 완료를 따로 봤습니다. 공식 웹에는 접속 보상과 경기 미션이 있지만 인정 조건 설명이 달랐습니다. 먼저 실제 규칙을 맞추고, 보상을 받았지만 경기를 안 한 계정에 준비 안내가 도움이 되는지 시험하는 안을 제안했습니다. 실제 전환 효과는 아직 모릅니다.

## 1분
대상은 2026년 9월 10일 신규·복귀 이벤트입니다. 접속 5일 보상과 경기 관련 미션이 분리돼 있어서 보상을 받았다는 것만으로 경기 참여 성과라고 보기는 어렵습니다. 본문은 플레이, 유의사항은 출석으로 설명하는 차이도 확인했습니다. 어느 쪽이 실제 서버 규칙인지는 내부 확인이 필요합니다. 이를 먼저 통일하고, 첫 보상을 받았으나 인정 경기가 없는 계정에 추가 준비 안내를 비교 시험하는 안을 만들었습니다. 보상은 바꾸지 않고 첫 24시간 경기 완료와 반복 경기, D7, 문의와 지급량을 함께 보겠습니다. 관심이나 시간이 원인이라면 안내를 늘리는 것으로 해결되지 않는다는 대안도 남겼습니다.

## 예상 질문 5개
1. 안내 부족이 원인이라는 증거가 있나?
없습니다. 문구 차이는 확인했지만 실제 미경기 원인은 미확인입니다. 이해 과업·문의·행동을 확인한 뒤 작은 안내 시험을 하자는 조건부 제안입니다.
2. 왜 보상을 더 주지 않나?
현재도 별도 보상이 있습니다. 원인 확인 없이 더 주면 지급량과 반복 수령만 늘 수 있어 먼저 규칙과 탐색 부담을 확인했습니다.
3. 퀵스쿼드를 첫 경기 전에 안내해도 되나?
모두가 보유했다고 가정하지 않습니다. 경기 미션 1일차 보상이므로 미보유자는 현재 선수단으로 시작하는 경로를 안내하고 보유자에게만 사용법을 보여줍니다.
4. 250만FC가 추가 예산인가?
아닙니다. 가상 1,000계정이 접속 보상 2,500FC를 모두 받는 총량 계산입니다. 실험의 순증 비용이 아닙니다. 두 집단의 계정당 실제 지급·사용과 작업 비용을 별도로 봐야 합니다.
5. 성공은 무엇으로 판단하나?
무작위 배정 계정 전체를 분모로 첫 24시간 인정 경기 완료를 비교합니다. 안내를 누른 사람만 골라 보지 않습니다. 반복 경기·D7 경기·문의·비정상 경기·지급량이 악화되지 않는지도 봅니다.

## 먼저 이해할 것
접속/보상/경기 완료/재참여 구분 / 규칙 정정은 양쪽 공통 / 보유하지 않은 이용권 오안내 금지 / D7 당일과 168시간 누적은 다름.
근거: B1 본문·유의사항 캡처, B2 보상안. 실험과 서버 규칙 확인은 미실행이다.
