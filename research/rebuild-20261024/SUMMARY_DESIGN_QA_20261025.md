# A·B·C 1페이지 요약 디자인 통일 — 2026-10-25

## 변경 범위와 보존
세 `*-summary.html`, 전용 `summary.css`, 재생성 원본 `build-summaries.mjs`만 제품 관련 수정했다. 상세 보고서, 공통 report.css/report-family.css, 메인 구조, 분석 내용, 공식 출처, 개인 경험과 모의안은 수정하지 않았다.

화면에서는 기존 report.css와 report-family.css(media=screen)를 재사용한다. 기본 글꼴은 상세와 동일한 Malgun Gothic → system-ui → sans-serif다. PC 본문 16px/1.85, 모바일 15px/1.85로 상세와 맞췄다. 배경·본문·강조·구분선은 동일한 CSS 변수를 사용하고 다크 모드도 그대로 상속한다.

- 상단: 공통 family-topbar 재사용. 왼쪽 포트폴리오, 오른쪽 전체 보고서·인쇄. 링크 높이 모두 44px.
- 제목: 공통 상세 기준 PC 최대 38px / 모바일 28px, 줄 간격 1.4, 동일 여백·줄바꿈 규칙. 게임명은 보조 정보, 실제 분석 제목은 h1.
- 본문: 상세 본문과 같은 최대 920px 읽기 영역, 외부 헤더 1120px, 모바일 좌우 18px.
- 사실 목록: 반복 테두리 카드를 구분선 목록으로 교체. 모바일에서는 라벨과 내용을 세로로 표시.
- 핵심 판단: 강조색 왼쪽 선과 굵기만 사용. 제안의 미실행 표시, KPI의 측정 계획 표시는 유지.
- 근거와 한계: 기존 문장을 별도 섹션으로 묶었다. 내용 자체는 변경하지 않았다.

## 내용·기능 검증
- 변경 전후 main의 텍스트를 공백 제외 비교: 새 섹션명 '근거와 한계'를 제외하면 일치. 새로운 분석·수치·KPI 없음.
- 6너비×3페이지의 인쇄 버튼이 window.print를 호출함을 확인. 운영체제 저장 대화상자 자동화 검증과는 다르다.
- 포트폴리오 및 전체 보고서 실제 이동 확인. 각 페이지 9개 링크의 파일·앵커 존재 확인.
- 원문 근거·제안·측정 정의·출처 등 본문/하단 링크도 390px에서 직접 클릭하여 목적 URL/앵커 확인.
- PDF는 실제 Chrome print 경로로 생성하고 Poppler 렌더링으로 확인. A·B·C 모두 A4 1페이지, 링크 주석 각 7개, 페이지 경계 밖 문자 0.
- 인쇄 내비게이션 숨김, 분석/사실/출처 텍스트 보존. 인쇄 본문 9.5pt, 사실 9pt, 보조 출처 8pt로 기존 수준 유지. 화면 크기를 종이에 맞춰 축소하지 않음.

## 의도적으로 남긴 차이
요약본은 이미지 없는 짧은 안내 문서이므로 상세 보고서의 대표 이미지·긴 표·부록은 복제하지 않았다. 본문 제목은 요약의 섹션 위계에 맞게 22px(모바일20px)로, 상세의 큰 섹션 제목보다 한 단계 작다. 색·글꼴·행간·상단 탐색·제목 체계·본문 열은 공통이다.

## 미검증 환경
iOS Safari 및 Android Chrome 실기기의 네이티브 인쇄/저장 대화상자, 물리 프린터 출력은 접근할 수 없어 검사하지 않았다. 이번의 모바일 검사는 Chrome 뷰포트/터치 에뮬레이션과 A4 PDF 출력 검증이다.
